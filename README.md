# 🎵 我的极简MP3播放器

一款基于 Electron 构建的桌面音乐播放器，支持本地 MP3 播放、频谱可视化、深浅色主题、迷你模式等功能。

## ✨ 功能特点

- 🎵 **本地音乐播放** - 选择文件夹，自动加载所有 MP3 文件
- 📋 **智能歌单** - 显示当前播放列表，支持点击切换歌曲
- 🔍 **实时搜索** - 快速过滤歌单中的歌曲
- 🎨 **深浅色主题** - 一键切换，保护眼睛
- 📊 **音频可视化** - 外圈频谱 + 内圈辐射 + 条形进度条频谱 + 粒子系统
- 🔀 **随机播放** - 打乱歌单，不中断当前歌曲
- 🔁 **播放模式** - 顺序播放 / 列表循环 / 单曲循环
- 🔊 **音量控制** - 滑块调节 + 一键静音
- 🖥️ **迷你模式** - 窗口缩小，背景显示封面图
- 🔔 **系统通知** - 换歌时 Windows 右下角弹窗
- ⌨️ **全局快捷键** - Ctrl+Shift+Space / ← / →
- 💾 **记忆歌单** - 关闭后自动恢复播放进度

## 🚀 快速开始

### 📥 下载安装（推荐普通用户）

1. 访问本仓库的 [Releases](https://github.com/code-smooth/mp3player_project/releases) 页面
2. 下载最新版本的 `我的MP3播放器 Setup 1.0.0.exe`
3. 双击运行安装程序，按提示完成安装
4. 安装完成后，桌面会出现快捷方式，双击即可使用

### 💻 开发模式（推荐开发者）

```bash
npm install
npm start

```

### 📦 打包成 exe

```bash
npm run dist:win
```

打包后的文件在 `dist` 文件夹中。
